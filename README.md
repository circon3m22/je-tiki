# JE TIKI

Минималистичный интернет-магазин украшений из дальневосточного дерева.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Скопируйте `.env.example` в `.env.local` и заполните публичные параметры Supabase. Без них каталог и локальная корзина продолжат работать, но оформление заказов будет недоступно: сайт не показывает ложное подтверждение и не теряет данные клиента.

## Подключение Supabase

1. Создайте проект Supabase.
2. Примените миграцию из `supabase/migrations`.
3. Разверните Edge Function `create-order`.
4. Включите анонимный вход в настройках Auth — он используется для корзины и заказа гостя.
5. Заполните `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` в `.env.local`.
6. Создайте пользователя-администратора и добавьте его UUID в таблицу `admin_profiles`.

В браузер передаётся только publishable key. Никогда не добавляйте secret key или `service_role` в переменные с префиксом `NEXT_PUBLIC_`.

## Развёртывание

Статический интерфейс собирается Next.js в `out` и публикуется GitHub Actions на GitHub Pages. Данные, авторизация, заказы и защищённые операции размещаются в Supabase.

Для GitHub Pages добавьте в настройках репозитория переменные Actions:

- `SUPABASE_URL`;
- `SUPABASE_PUBLISHABLE_KEY`.

Workflow запускается при отправке изменений в ветку `main` или `master`. Юридические документы хранятся в таблице `legal_documents` и редактируются в разделе «Документы» панели управления.
